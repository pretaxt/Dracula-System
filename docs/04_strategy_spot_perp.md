> **策略复杂度**:⭐⭐(中低)

## 序言:为什么是独立策略?

期现套利和资金费率套利**结构几乎完全相同**:

| 维度 | 资金费率套利 | 期现套利 |
|---|---|---|
| 持仓结构 | 现货多 + 永续空 | 现货多 + 永续空 |
| Delta | 0(中性) | 0(中性) |
| 收益来源 | 资金费率 | 永续溢价(premium) |
| 持仓时长 | 几天-几周 | 几小时-几天 |

**那为什么是两个策略而不是合并?**

**关键区别:入场信号不同**

- **资金费率套利**:看 **APR**(年化资金费率),APR > 15% 才进场
- **期现套利**:看 **永续溢价百分比**(perp_price - spot_price) / spot_price

这两个信号**通常**同向(资金费率高 ↔ 永续溢价大),但**不总是**:

- 有时永续溢价突然扩大(短期情绪),但资金费率还没跟上调整(资金费率有惯性,8 小时一次)
- 这个"溢价扩大但资金费率还没反应"的窗口,就是期现套利的机会

所以期现套利**抓的是更短的、更频繁的、更小的机会**;资金费率套利**抓的是更长、更稳、更大的机会**。

**两个策略并行的意义**:互补覆盖不同时间尺度的市场低效。

## 一、策略原理

### 1.1 永续溢价(Perp Premium)

```
永续溢价 = (永续价格 - 现货价格) / 现货价格 × 100%
```

例如:
- BTC 现货 $60,000
- BTC 永续 $60,090
- 溢价 = +0.15%

### 1.2 为什么会出现溢价?

资金费率机制理论上应该把溢价压到 0,但实际不会:

1. **资金费率结算频率有限**:8 小时一次,中间溢价可能跑得比较开
2. **市场情绪冲击**:某新闻出来后,几秒内永续就被拉得比现货高
3. **流动性差异**:永续流动性通常更好,价格反应更快

我们的策略是**等溢价扩大到一定程度,做空溢价**(做空永续 + 做多现货),等溢价回归正常时平仓。

### 1.3 与资金费率套利的关系

实际上,**期现套利 = 资金费率套利的"短期版本"**。

举例:
- 永续溢价 0.15% → 做空永续 + 做多现货
- 6 小时后,溢价收敛到 0.05% → 平仓,赚 0.10% × 仓位

整个周期 6 小时,根本没等到资金费率结算。所以期现套利的收益**主要来自"永续价格回归"**,而不是资金费率。

## 二、数学模型

### 2.1 单次套利的收益

```
单次毛收益 = 进场溢价 - 出场溢价 - 双向手续费 - 双向滑点
```

例如:
- 进场:溢价 0.20%,做多现货 $1,000 + 做空永续 $1,000
- 出场:溢价 0.05%,平仓
- 毛收益:0.15% × $1,000 = $1.50
- 手续费(4 笔,每笔 0.04%):0.16% × $1,000 = $1.60
- 滑点(估 0.05%):$0.50

**净亏损**:$1.50 - $1.60 - $0.50 = **-$0.60**

⚠️ **这是为什么期现套利的进场门槛很关键**——如果溢价不够大,根本扛不过手续费。

### 2.2 进场门槛计算

让我们反推:多大的溢价才值得做?

```
最小进场溢价 = 双向手续费 + 双向滑点 + 期望最低利润
            = 0.16% + 0.10% + 0.10%
            = 0.36%
```

也就是说,**永续溢价至少要 0.36%(36 bps)才值得开仓**,否则净亏损概率高。

### 2.3 收益频率

资金费率套利每个仓位平均持有几天-1 周。期现套利每个仓位通常 几小时-1 天,但**机会更多**:

| 维度 | 资金费率套利 | 期现套利 |
|---|---|---|
| 单仓持有 | 5-7 天 | 0.5-1 天 |
| 单仓收益 | 0.5%-1.5% | 0.1%-0.3% |
| 月度仓位数 | 5-10 | 30-60 |
| 月度总收益 | ≈ 5%-10% | ≈ 5%-10% |

最终收益相当,但**期现套利交易频率高 6 倍**,意味着:

- 优点:对市场各种行情都有机会
- 缺点:**手续费成本被放大**,任何一次执行失败都很伤

## 三、执行流程

### 3.1 与资金费率套利完全相同的双腿原子化

执行机制跟 02 文档讲的一模一样,这里不重复。**关键差异**:

1. **更敏感的滑点保护**:期现套利毛收益小,滑点超过 0.1% 就要取消订单(资金费率套利 0.3%)
2. **更短的 timeout**:5 秒不成交就转市价(资金费率套利可以更耐心)
3. **更频繁的扫描**:每 5 秒扫一次(资金费率套利每 30 秒)

### 3.2 出场时机

| 条件 | 阈值 |
|---|---|
| **溢价收敛 70%** | current_premium < 0.3 × entry_premium |
| **溢价反向**(变成负溢价) | current_premium < 0 |
| **持仓超过 24 小时** | holding_hours > 24 |
| **Tier 风控触发** | 强平 |

## 五、风险与亏损场景

### 5.1 滑点爆炸(最常见杀手)

期现套利的边际收益本来就薄,**任何一次滑点超预期就赔**。

**场景**:进场扫描时溢价 0.40%,挂限价单准备建仓。但下单的 100ms 内,溢价已经收敛到 0.20%,你的限价单只能成交在更差的价位。

**亏损**:可能直接进场就 -0.05% 浮亏,叠加手续费,基本不可能赚回来。

**系统保护**:
- `max_slippage_pct: 0.10`——超过 0.1% 取消订单
- `premium_must_persist_seconds: 30`——溢价稳定 30 秒以上才进场,避免短暂扰动

### 5.2 资金费率反向(中频)

**场景**:你做空永续,但建仓后赶上资金费率结算,资金费率 +0.04%(年化 44%),你要付钱。

但因为你的持有时间短(几小时),通常只赶上 0 或 1 次结算,影响有限。

**系统保护**:进场时如果距离下次资金费结算 < 1 小时,适度提高进场门槛。

### 5.3 单边敞口的可怕

**场景**:开仓时只成交了现货腿,永续腿没成交。回滚时市价单关掉现货,但市场已经动了 0.2%。

**亏损**:净亏损 0.2% × 仓位

**系统保护**:同 02 文档,严格的回滚机制。**期现套利对回滚速度要求最高**。

## 八、与其他策略的协同

### 8.1 与资金费率套利的资源冲突

**最重要**:这两个策略**抢同一个资源**(`{exchange}:{symbol}:spot:long` + `{exchange}:{symbol}:perp:short`)。

**协同方案**:
- **资金费率套利优先级更高**(主力策略)
- 期现套利发现资源被占用 → 跳过该机会,扫描下一个

**实战建议**:
- 资金费率套利在主流币种上(BTC、ETH、SOL)
- 期现套利在中等市值币种上(AVAX、ARB、DOGE 等)
- 这样自然分离,资源冲突最少

### 8.2 与基差套利不冲突

期现套利用永续,基差套利用永续 + 季度。除非两个策略都想在 BTC 永续上**做空**,否则不冲突。

## 十、总结

5 句话:

1. **本质**:抓"短期溢价扩大 → 收敛"的窗口,跟资金费率套利不同时间尺度
2. **门槛**:溢价 ≥ 0.36% 才值得做,否则手续费扛不住
3. **频率**:每月 30-60 个仓位,持有 4-12 小时
4. **风险**:滑点是最大杀手,**必须严格控制**
5. **协同**:跟资金费率套利避免资源冲突,主流币给资金费率套利,中等币给期现套利
