## 一、什么是基差?

### 1.1 永续合约 vs 季度合约 vs 现货

要理解基差,先理清三种合约的区别:

| 类型 | 到期日 | 资金费率 | 价格特性 |
|---|---|---|---|
| **现货** | - | 无 | 真实成交价 |
| **永续合约** | 永远不到期 | 每 8 小时(或 1 小时)结算 | 用资金费率拉回现货价 |
| **季度合约** | 有(通常每季度一次到期) | **无资金费率** | 自然在到期前与现货价收敛 |

### 1.2 基差(Basis)的定义

**基差** = 衍生品价格 - 现货价格

具体到我们的策略:

```
永续 vs 季度基差 = 永续价格 - 季度价格
```

**重要**:同一个币种(比如 BTC),在同一个交易所(比如 Binance),会同时存在:
- 现货市场($60,000)
- 永续合约($60,020)  ← 比现货稍贵,因为多头看涨情绪
- 季度合约($60,500)  ← 比永续更贵,因为隐含了"未来 X 天后"的预期

这三者的价格**通常**是 现货 < 永续 < 季度,但偶尔会反过来。

### 1.3 基差为什么会出现?

**永续 vs 现货基差**:已经被资金费率机制拉得很近了(通常差 0.01% - 0.1%)。我们在 02 文档讲过资金费率套利,本质上是吃这个基差。

**季度合约 vs 现货基差**:季度合约**没有资金费率**,所以基差只会通过"自然到期收敛"来消除。这意味着:

- 牛市:季度合约比现货贵很多(比如 +2%),因为大家认为未来价格会涨
- 熊市:季度合约比现货便宜(比如 -1%),因为大家认为未来会跌

**永续 vs 季度基差**:这才是本策略要套的对象。永续被资金费率压在现货附近,季度可以高于或低于现货很多。所以**永续 vs 季度的基差,反映了"市场对未来的预期"**。

## 二、套利的核心思想

### 2.1 基差总会收敛

**关键事实**:**季度合约到期时,价格必然等于现货价格**。这是合约规则——到期日按现货指数价结算。

所以无论现在基差多大,**到期那一刻基差必然 = 0**。

如果当前基差 = +2%(季度比永续贵 2%),并且距离到期还有 60 天,那么这 60 天里:
- 如果**整体市场没有结构性变化**:基差会平滑收敛到 0
- 如果**情绪反转**:基差可能先扩大再收敛
- 但**到期那一刻**:基差铁定 = 0

### 2.2 我们怎么吃这个基差?

**核心操作**(假设当前季度合约比永续贵):

```
季度合约价格:$60,500
永续合约价格:$60,000
基差:+$500(季度高 0.83%)
```

**建仓**:
```
做多永续合约(便宜的)        +1 BTC × $60,000
做空季度合约(贵的)          -1 BTC × $60,500
─────────────────────────────────────
组合净 Delta = 0
组合"锁住"了 $500 的基差
```

**到期或基差收敛时**:
```
情况 A:基差自然收敛到 0
        永续:$60,000 → $61,000(涨了 $1000)
        季度:$60,500 → $61,000(涨了 $500)
        多头永续赚 $1000,空头季度亏 $500
        净赚 $500 = 当初的基差

情况 B:到期前自动平仓
        永续:$60,000 → $58,000
        季度:$60,500 → $58,000
        多头永续亏 $2000,空头季度赚 $2500
        净赚 $500 = 当初的基差

情况 C:基差进一步扩大(浮亏 → 持有等收敛)
        永续:$60,000 → $59,500
        季度:$60,500 → $61,500(基差 +$2000)
        当前浮亏:$2000 - $500 = $1500
        但只要持有到收敛,最终还是赚 $500
```

**重点**:无论价格涨跌,只要持有到收敛,就赚 $500 ÷ 60 天 = 每天 0.014%,年化约 5%。

### 2.3 与资金费率套利的区别

| 维度 | 资金费率套利 | 跨所基差套利 |
|---|---|---|
| 收益来源 | 资金费率结算(每 8 小时一次) | 基差收敛(连续) |
| 持有时长 | 几天-几周 | 几周-几个月(到季度合约到期) |
| 资金费率风险 | 高(可能反转) | 无(季度合约没有资金费率) |
| 杠杆 | 通常 3 倍 | 可以 5 倍以上(因为方向更确定) |
| 容量 | 小币种 $5万-$50万 / 主流币 $1M+ | 主流币能上 $1M+ |
| 适合资金量 | $1k 起 | $5k 起(因为持有时间长) |

## 三、数学模型

### 3.1 基差年化计算

```
基差年化收益率 = (基差 / 现货价格) × (365 / 到期剩余天数)
```

例如:
- 现货价格 $60,000
- 季度合约价格 $60,500(基差 +$500,即 +0.83%)
- 到期剩余 60 天
- 年化:0.83% × (365/60) = **5.05%**

### 3.2 净收益公式

```
净 APR = 基差年化
       − 永续端手续费(年化)
       − 季度端手续费(年化)
       − 滑点(年化)
       − 永续端的资金费率成本(如果做多永续,要付资金费!)
```

**关键**:做多永续要**付资金费**!这是这个策略最容易被忽视的成本。

如果当前永续资金费率是 +0.02%(年化 22%),你做多永续就要每 8 小时付 0.02%。这个成本可能比基差收敛收益还高,导致策略整体亏钱。

**因此**:这个策略**只在资金费率为负或接近 0 时才适合做**——这种情况下,你做多永续不仅不付资金费,反而能赚资金费。

### 3.3 三种典型场景

| 场景 | 基差年化 | 资金费成本 | 手续费+滑点 | **净 APR** | 是否值得做 |
|---|---|---|---|---|---|
| 牛市,基差正 + 资金费正 | +15% | -22% | -3% | **-10%** | ❌ 不做 |
| 平淡,基差正 + 资金费 0 | +5% | 0% | -3% | **+2%** | ⚠️ 边缘 |
| 熊市,基差负 + 资金费负 | +10%(反向操作) | +5% | -3% | **+12%** | ✅ 做 |
| 极端事件,基差暴涨 | +30% | -15% | -5% | **+10%** | ✅ 做 |

### 3.4 反向操作(基差为负时)

如果**永续 > 季度**(基差为负,通常发生在熊市或极度恐慌时):

```
基差:-$500(季度比永续便宜 0.83%)
```

**反向建仓**:
```
做空永续合约            -1 BTC × $60,500
做多季度合约            +1 BTC × $60,000
─────────────────────────────────────
组合净 Delta = 0
等待基差收敛到 0(也是赚 $500)
```

熊市做空永续还能赚资金费率,所以这种情况收益更好。

## 四、执行流程

### 4.1 开仓:同所双腿原子化

跟资金费率套利一样,**必须双腿原子化**。这里是同一个交易所的两个不同合约,所以速度比跨所更好。

```
Step 1:同时挂限价单
        ┌──────────────────────────────┐
        │ Binance 永续:做多 0.1 BTC   │
        │ 限价 @ $60,005               │
        └──────────────────────────────┘
        ┌──────────────────────────────┐
        │ Binance 当季:做空 0.1 BTC   │
        │ 限价 @ $60,495               │
        └──────────────────────────────┘

Step 2:等待两腿成交(timeout 5 秒)

Step 3:回滚处理(只成交一边时)
        ⚠️ 重点:如果只成交一边,立即用市价单完成另一边
        因为基差锁不住的话,这就变成裸单边了

Step 4:确认 Delta 中性,锁定资源,记录基差
```

### 4.2 持仓监控

```python
async def monitor_position(position):
    # 1. Delta 偏离(理论上不会变,因为永续和季度的 Delta 都是 1)
    # 但如果是反向 Delta 的合约(coin-margined),要重新计算

    # 2. 资金费率成本累计
    if position.is_long_perp:
        funding_cost = current_perp_funding * notional
        position.cumulative_funding_cost += funding_cost

    # 3. 基差变化监控
    current_basis = perp_price - quarterly_price
    basis_change = current_basis - position.entry_basis

    # 浮亏报警
    if basis_change > position.entry_basis * 0.5:  # 基差扩大 50%
        await notify("WARN", f"基差扩大,当前浮亏 ${basis_change}")

    # 4. 季度合约到期日提醒
    days_to_expiry = (position.quarterly_expiry - now).days
    if days_to_expiry < 7:
        await notify("INFO", f"季度合约 7 天后到期,准备平仓")

    # 5. 强制平仓:到期前 3 天
    if days_to_expiry < 3:
        await close_position(position, reason="approaching_expiry")
```

### 4.3 平仓时机

**自动平仓的几种情况**:

1. **基差收敛 80% 以上**:已经赚到大部分,锁定收益
2. **季度合约到期前 3 天**:必须强制平仓,避免到期结算复杂性
3. **资金费率反向**:做多永续期间资金费率突然变正且很大(>+0.04%),成本超过预期,先平
4. **Tier 3 风控触发**:跟资金费率套利一样

## 五、出场策略

| 条件 | 阈值(默认) | 理由 |
|---|---|---|
| **基差收敛 80%** | abs(current_basis) < 0.2 × entry_basis | 已赚大部分,锁定收益 |
| **季度到期前 3 天** | days_to_expiry < 3 | 强制,避免到期结算混乱 |
| **资金费率成本超基差年化** | funding_cost_annualized > entry_basis_apr | 成本翻车,止损 |
| **基差进一步扩大 100%** | abs(current_basis) > 2 × entry_basis | 异常,先撤 |
| **持仓 60 天** | holding_days > 60 | 时间太长,机会成本高 |

## 七、风险与亏损场景

### 7.1 资金费率突然飙升(最常见)

**场景**:你做多永续 + 做空季度,建仓时永续资金费率 0%。但市场情绪突然牛市,永续资金费率涨到 +0.04%(年化 44%)。

**亏损方式**:
- 你做多永续要付资金费 → 每 8 小时付 0.04% × 仓位
- 即使基差最终收敛你也赚回来,但资金费成本可能吞掉大部分

**系统保护**:
- `max_perp_funding_rate: 0.005` —— 进场时资金费率超 0.005% 不进场
- `funding_cost_alert_pct: 50` —— 累计资金费成本占基差 50% 时告警
- 如果累计超过 80%,自动平仓

**防不住的部分**:进场后资金费率突变,你已经在仓位里,只能承受。

---

### 7.2 基差到期前 1 周突然扩大(罕见但发生过)

**场景**:你建仓时基差 +0.8%,持有 50 天后基差不仅没收敛,反而扩大到 +1.5%。

**亏损方式**:
- 浮亏 0.7% × 仓位
- 你被迫继续等到期收敛
- 期间还要继续付资金费

**系统保护**:
- `basis_change_alert: 100%` —— 基差扩大到进场时的 2 倍触发告警
- 但**不强制平仓**——因为强平意味着锁死亏损

**防不住的部分**:这是**真实存在的尾部风险**。LUNA 崩盘前 BTC 季度基差扩大过 3%。

**实战建议**:
- 不要把超过 50% 的资金集中在一个季度合约上
- 离到期超过 30 天的合约,基差扩大风险更大

---

### 7.3 季度合约流动性差

**场景**:Binance 当季合约还好,但**次季度合约**(3 个月以上的)流动性可能差很多。

**亏损方式**:
- 平仓时挂限价单挂不出去,只能市价单
- 滑点 0.3% - 1%

**系统保护**:
- 进场前流动性检查:订单簿前 5 档总深度 > $100,000
- 只做当季合约(`min_days_to_expiry: 14, max_days: 90`)

**防不住的部分**:极端行情下流动性瞬间消失。

---

### 7.4 交易所到期结算异常

**场景**:Binance 季度合约到期那一刻,服务器卡顿,你的合约被强平时滑点很大。

**亏损方式**:
- 到期结算价偏离现货指数价 0.5%

**系统保护**:
- 强制到期前 3 天平仓,**永远不让合约到期结算**
- 这是关键设计——主动控制结算时机

**防不住的部分**:到期前 3 天市场剧烈波动,3 天前的强平也可能滑点。

---

### 7.5 隐性成本:借币利息(coin-margined 合约)

**场景**:OKX、Bybit 部分季度合约是 **币本位(coin-margined)**——保证金是币而不是 USDT。这种合约盈亏方式不同。

**亏损方式**:
- Delta 不是恒定的(币价涨,你的空仓敞口实际在变小)
- 需要更复杂的对冲逻辑

**系统保护**:
- **只做 USDT 本位合约**(`require_usdt_margined: true`)
- 自动跳过 coin-margined 合约

**防不住的部分**:无,只要不做 coin-margined 就行。

---

### 7.6 风险总结表

| 风险 | 发生概率 | 单次损失 | 系统能防几成 |
|---|---|---|---|
| 资金费率飙升 | 高(月度) | 0.5%-2% | 60% |
| 基差扩大 | 中(季度发生) | 1%-3% 浮亏 | 50% |
| 季度合约流动性差 | 低 | 0.3%-1% | 80% |
| 到期结算异常 | 极低 | 0.5% | 95% |
| coin-margined 误操作 | 仅一次 | 5%+ | 100%(代码强制过滤) |

## 八、回测要求

### 8.1 数据需求

- **历史时间窗口**:24 个月(基差有季节性,需要看多个周期)
- **数据频率**:
  - 现货 / 永续 / 季度价格:1 小时级别
  - 资金费率:每个结算周期
  - 季度合约到期日:精确到分钟
- **数据源**:
  - Binance / OKX / Bybit 官方 API 都支持
  - 季度合约历史数据较少机构提供,可能需要自己存

### 8.2 回测要模拟的特殊情况

**比资金费率套利多了几个**:

```python
1. 季度合约换月(roll-over)
   - 当季合约到期前几天,需要换到次季合约
   - 换月会有滑点和短暂裸露

2. 双向资金费率成本
   - 不只是付资金费,有时候是收(永续端做空时)
   - 必须按方向区分

3. 持仓周期更长
   - 平均持仓 30-45 天
   - 中间任何一次黑天鹅都可能浮亏 3-5%

4. 基差的非线性
   - 基差不是线性收敛的
   - 临近到期会加速收敛
   - 中间可能反复扩大
```

### 8.3 关键指标

| 指标 | 通过标准 |
|---|---|
| **Sharpe Ratio** | > 1.2(比资金费率略低,因为持仓久,波动大) |
| **Max Drawdown** | < 5% |
| **Win Rate** | > 80%(到期收敛是确定性的) |
| **Avg Holding Days** | 25-50 天 |
| **基差捕获率** | > 70%(进场时锁的基差,实际拿到几成) |
| **失败的换月次数** | < 5%(换月时单边露露占比) |

## 九、Paper Trading + 实盘阶段

跟资金费率套利类似,但**周期更长**:

### 9.1 Paper Trading

- **运行时长**:**至少 1 个月**(因为基差持有周期长,2 周不够看)
- **必须经历**:1 次完整的"建仓 → 持有 → 接近收敛 → 平仓"周期

### 9.2 实盘阶段

```
Stage 1:$200 实盘 / 1 个月
  - 跑通流程,看真实基差捕获率
  - 至少 1 次成功平仓

Stage 2:$500 实盘 / 1 个月
  - 同时持有 2 个仓位
  - 至少经历 1 次"季度合约换月"

Stage 3:$1,000 实盘 / 持续
  - Phase 0 目标资金量
```

每阶段切换需要前一阶段的"完整周期"通过,而不是简单的"7 天没出问题"。

## 十、与其他策略的协同

### 10.1 与资金费率套利:互斥

如果资金费率套利已经在 Binance 持有 BTC 永续空头,**基差套利不能在 Binance 持有 BTC 永续多头**——这两个会互相对冲掉,毫无意义,而且占用双倍保证金。

**资源锁机制**:`{exchange}:{symbol}:perp:{side}` 粒度。

### 10.2 与期现套利:互补

期现套利是"现货 + 永续",基差套利是"永续 + 季度"。

**理论上可以同时**:
- 现货多
- 永续空(资金费率套利的腿)
- 永续多 + 季度空(基差套利)

但仔细看,永续多和永续空在同一个币上互相抵消了!所以需要在不同币种上做,或者放弃同币种叠加。

### 10.3 资金分配建议
