## 一、什么是稳定币套利

### 1.1 稳定币的"应该"价格

主流稳定币:USDT、USDC、DAI、FDUSD、TUSD、BUSD(已下架)、PYUSD...

它们都"应该" = $1 USD。但**实际**经常偏离:

```
正常情况:
  USDT/USD = 0.9998 - 1.0002
  USDC/USD = 0.9999 - 1.0001
  DAI/USD  = 0.9995 - 1.0005

极端情况(如 SVB 危机 2023年3月):
  USDC 一度跌到 $0.87
  Maker 上 DAI 跟着跌
  所有 USDC 持有者恐慌抛售
```

### 1.2 套利机会从哪来

#### 类型 A:稳定币之间的偏离

```
USDT/USDC = 0.9985(USDT 比 USDC 便宜 0.15%)

操作:
  买 USDT(便宜)
  卖 USDC(贵)
  等回归到 1:1 时反向操作
```

#### 类型 B:同一稳定币在不同交易所的价差

```
USDT 在 Binance:$1.0001
USDT 在 Kraken:$0.9985

操作:
  在 Kraken 买 USDT(便宜)
  在 Binance 卖 USDT(贵)
  价差 0.16%
```

⚠️ 这种跨所稳定币套利**有提币风险**:从 Kraken 转到 Binance 需要 5-30 分钟,价差可能消失,还要付 gas。

我们的系统**主要做类型 A**(同所内稳定币兑换)。

#### 类型 C:DeFi 收益率与现货的偏离

```
某稳定币 LP 提供 8% APY(年化)
你买入这个币 + 加 LP + 对冲价格
比直接持有 USDT 收益高 5%
```

这其实是 **DEX LP 策略**,详细在第 17 章讲。

### 1.3 我们具体做什么

**主要场景**:同一交易所内,**多稳定币之间的小额偏离**。

```
监控的对儿:
  USDT/USDC
  USDT/DAI
  USDT/FDUSD(Binance)
  USDC/DAI
  USDC/FDUSD
```

**触发**:任意对儿偏离 0.10% 以上就交易。

## 二、数学模型

### 2.1 收益公式

```
单次毛收益 = 偏离百分比
扣手续费(双向 0.1%):0.20%
扣滑点(估 0.02%):0.02%

净收益 = 偏离% - 0.22%
```

**所以最低进场门槛:**0.25%(否则不赚)

### 2.2 实际预期收益

| 偏离程度 | 月度发生频率 | 操作单次收益 |
|---|---|---|
| 0.10%-0.25% | 经常(每天数次) | 不操作(亏手续费) |
| 0.25%-0.50% | 中(每周数次) | +$0.5-1.5 (per $1k) |
| 0.50%-1.00% | 少(每月几次) | +$3-7 (per $1k) |
| 1%-5% (极端事件) | 罕见(几个月一次) | +$8-50 (per $1k) |

**月度合理预期**:
- 平静月份:$2-$5 (per $1k)
- 普通月份:$5-$15 (per $1k)
- 极端事件月份:$50-$300 (per $1k)

**长期平均**:**月化 0.2%-0.5%**,符合开头预期。

## 三、执行流程

跟三角套利**几乎一样**——双腿原子化:

```python
async def execute_stablecoin_arb(pair: str, direction: str, amount: Decimal):
    """
    pair = "USDT/USDC"
    direction = "buy_usdt"(买 USDT 卖 USDC)或 "sell_usdt"
    """
    if direction == "buy_usdt":
        # 在 USDT/USDC 这个对里买 USDT(意味着卖 USDC 给系统换 USDT)
        order = await exchange.place_order(
            symbol="USDC/USDT",
            side="sell",   # 卖 USDC
            amount=amount,
            type="limit",
            price=current_price * Decimal("1.0005"),
            time_in_force="IOC"
        )
    # ... 类似处理

    # 立即记录
    await record_arb(pair, direction, amount, order)
```

**比三角套利更简单**——只有 1 笔订单(因为是同币对的内部转换),不需要 3 步原子化。

## 五、风险与亏损场景

### 5.1 稳定币真的脱锚(罕见但致命)

**真实案例**:
- 2023 年 3 月 SVB 危机,USDC 一度跌到 $0.87(脱锚 13%)
- 2022 年 5 月 UST 崩盘(归零,但 UST 不算我们做的稳定币)
- 2024 年 3 月 USDe 一度跌到 $0.97

**场景**:你看到 USDC 偏离 0.5% → 自动套利买入 → 后续 USDC 继续跌到 0.90 → 你被困

**亏损方式**:
- 短期内浮亏 5%-10%
- 长期可能完全归零(如 UST)

**系统保护**:
- `pause_on_extreme_deviation: 3.0` — 偏离超 3% 暂停(可能是黑天鹅)
- 极端事件自动通知用户

**防不住的部分**:从"小偏离"到"黑天鹅"可能 1-2 小时内发生,系统可能已经买了一批

**实战建议**:
- **不做 USDe / FDUSD / 算法稳定币的套利**,只做 USDT/USDC/DAI
- 黑天鹅时人工干预,不要让系统继续自动操作

### 5.2 流动性陷阱

**场景**:某个稳定币对深度很差,你 $1000 买入会推高价格 0.3%

**亏损方式**:
- 实际买入价比预期高
- 套利利润被滑点吃光

**系统保护**:
- 进场前订单簿深度检查(前 5 档 > $20k)
- 单次执行金额限制($500)

### 5.3 风险总结

| 风险 | 频率 | 单次损失 | 系统能防多少 |
|---|---|---|---|
| 稳定币脱锚(USDC/DAI) | 1-2 年一次 | 5%-30% | 50%(暂停机制) |
| 算法稳定币归零(UST 类) | 罕见 | 100% | 100%(不做) |
| 流动性陷阱 | 持续存在 | 0.05%-0.2% | 90%(深度检查) |
| 跨所提币风险 | 我们不跨所做 | - | 100% |
