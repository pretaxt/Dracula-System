## 一、期权基础概念(必读)

### 1.1 什么是期权

期权是一种**权利**(不是义务):

- **看涨期权(Call)**:持有者有权(不是必须)在到期日按约定价格买入标的
- **看跌期权(Put)**:持有者有权在到期日按约定价格卖出标的

**举例**:
- 你买一手 BTC Call,执行价 $65,000,到期 7 天
- 7 天后,如果 BTC > $65,000,你可以"行权"——按 $65,000 买入,然后立刻按市场价卖出,赚差价
- 7 天后,如果 BTC < $65,000,你"不行权",损失全部权利金

### 1.2 期权的价格构成

期权价格(权利金)由两部分组成:

```
权利金 = 内在价值 + 时间价值
```

**内在价值**:行权立即能赚多少
- BTC 现价 $66,000,Call 执行价 $65,000 → 内在价值 = $1,000
- BTC 现价 $64,000,Call 执行价 $65,000 → 内在价值 = $0(行权不划算)

**时间价值**:对未来不确定性的"溢价"
- 离到期还有 30 天 vs 1 天,时间价值差异巨大
- 接近到期时,时间价值快速衰减(Theta)

### 1.3 隐含波动率(IV) vs 已实现波动率(RV)

这是期权策略的**核心**:

**IV(Implied Volatility)**:
- 从期权价格反推出来的"市场预期波动率"
- 是市场对未来波动的**预测**
- 当期权贵 → IV 高;当期权便宜 → IV 低

**RV(Realized Volatility)**:
- 标的资产的**实际**历史波动率
- 用过去 N 天的价格计算出来

**关系**:
- IV > RV:市场觉得未来会比过去波动得更厉害(可能贵)
- IV < RV:市场觉得未来会比过去波动得更小(可能便宜)
- IV ≈ RV:正常状态

**套利思路**:
- 当 IV 远高于 RV → **卖出期权**(收溢价)
- 当 IV 远低于 RV → **买入期权**(便宜买入波动)

但这不是"无风险套利"——你赌的是"未来 N 天 RV 会回归到平均水平",但市场可能突然狂跳让你判断错误。

## 二、Greeks 入门(简化版)

期权价格对各种因素都敏感,这些敏感度叫 **Greeks**:

| Greek | 含义 | 例子 |
|---|---|---|
| **Delta(Δ)** | 标的涨 $1,期权价格涨多少 | Δ=0.5 表示 BTC 涨 $1 期权涨 $0.5 |
| **Gamma(Γ)** | Delta 变化的速度 | Δ 不是固定的,会随价格变 |
| **Theta(Θ)** | 时间衰减 | 每过一天,期权贬值多少 |
| **Vega(ν)** | IV 变化的影响 | IV 涨 1%,期权价格涨多少 |
| **Rho(ρ)** | 利率变化的影响 | 加密期权一般忽略 |

**专业的"Greeks 中性"对冲**:

```
组合 Delta = 0(价格变化不影响)
组合 Gamma = 0(Delta 变化速度也对冲)
组合 Vega = 0(IV 变化也不影响)
剩下的:Theta(时间收割,如果是负 Theta 就在亏)
```

要做到这种"完美中性",需要**至少 5-10 个不同的期权合约组合**,每个合约保证金 $500-$5000,总资金 **$30k 起步**。

**所以小资金能做什么?** 简化的"近似中性",至少**控制 Delta 到接近 0**,其他 Greeks 听天由命。

## 三、可行的小资金策略

### 3.1 Long Volatility(买入波动率)

**适用场景**:IV 远低于 RV(预计未来会比当前 IV 更波动)

**操作**:
- 买入 ATM(平值)Call + ATM Put,**相同执行价 + 相同到期日**
- 这叫 **Long Straddle**
- 不管价格涨还是跌,只要动得够狠,就赚钱

**例子**:
- BTC 现价 $60,000,IV 35%,RV(过去 30 天)55%
- 你判断 IV 被低估,**买入 7 天后到期的 $60k Call + $60k Put**
- 总成本(权利金):$1500(Call) + $1500(Put) = $3,000
- 7 天后 BTC 涨到 $63,000:Call 内在价值 $3,000,Put 归零,你赚 $3000-$3000 = $0(打平)
- 7 天后 BTC 涨到 $66,000:Call 内在价值 $6,000,Put 归零,你赚 $3,000(100% 收益)
- 7 天后 BTC 在 $58,000-$62,000 区间内:你**亏 $1,000-$2,000**(因为时间价值衰减)

**风险**:
- BTC 在到期前不动 → 时间价值衰减,亏损 30%-100%
- 这是**最直接的方向性赌博**——不是赌涨跌,是赌"会不会大幅波动"

### 3.2 Short Volatility(卖出波动率)

**适用场景**:IV 远高于 RV(预计 IV 会回落)

**操作**:
- 卖出 ATM Call + ATM Put(Short Straddle)
- **极度危险**——理论亏损无上限

**为什么危险**:
- 卖 Call:如果 BTC 暴涨,你要"履约"按低价卖出 BTC,亏损可以无限大
- 卖 Put:如果 BTC 暴跌,你要按高价买入 BTC,亏损可以达 100%

**所以小资金不应该做这个**——除非你愿意承担"一次黑天鹅亏光所有资金"的风险。

### 3.3 折中:Iron Condor(铁鹰)

**适用场景**:预计 IV 会回落,但又想限制亏损

**操作**:同时四条腿
- 卖出 OTM(虚值)Call($65k Call)
- 买入更虚的 Call($70k Call) → 限制上行亏损
- 卖出 OTM Put($55k Put)
- 买入更虚的 Put($50k Put) → 限制下行亏损

**特点**:
- 最大盈利:卖出的两个期权权利金之和减去买入的两个
- 最大亏损:被限制(因为有"保险"腿)
- 适合"预期价格不会大动"的市场

**Phase 0 实战**:
- 资金需求约 $1,500-$3,000(四腿)
- 单仓最大盈亏约 $300-$500
- 月化收益约 5%-15%(如果连续多月不爆仓)
- 但**一次"黑天鹅"可能爆仓**(超过保险范围)

## 六、风险与亏损场景

### 6.1 时间价值衰减(Theta)— 慢性亏损

**场景**:你买入 7 天到期 ATM Straddle,但 BTC 价格在到期前几乎没动。

**亏损方式**:
- 时间价值持续衰减
- 每天损失 5%-15% 的权利金价值
- 7 天后归零

**系统保护**:`max_dte_holding: 3`——离到期 3 天强制平仓,锁定剩余价值。

**防不住的部分**:即使 3 天前平仓,你已经损失大部分时间价值。

### 6.2 IV 突然崩塌(Vega 风险)

**场景**:某重大事件(美联储议息、ETF 决策)结束后,IV 从 60% 暴跌到 35%。

**亏损方式**:
- 你买入的期权 Vega 是正的 → IV 跌,期权贬值
- 一夜之间损失 30%-50%

**系统保护**:`iv_percentile_extreme: 15`——只在 IV 已经在历史低位时才买入,防止"高位接盘"。

### 6.3 黑天鹅(Short 一方的灾难)

**场景**:你卖出 BTC Put,执行价 $55k。BTC 突然崩到 $45k。

**亏损方式**:
- 你必须按 $55k"接货"
- 实际市场价 $45k
- 单笔亏损 = $10k × 期权数量

**系统保护**:**禁用单纯卖空波动率**(`enable_short_volatility: false`)。如果要卖,必须用 Iron Condor(有保险腿)。

### 6.4 流动性陷阱

**场景**:你买的某个执行价的期权,只有 Deribit 一家做市商在挂单,买卖价差很大。

**亏损方式**:
- 平仓时只能接受恶劣的卖出价
- 滑点 5%-10%

**系统保护**:只交易 ATM 附近的主流期权,远离深度 OTM。

### 6.5 风险总结表

| 风险 | 频率 | 单次损失 | 防御 |
|---|---|---|---|
| Theta 衰减 | 每天发生 | 5%-15% / 天 | 严格控制持仓时间 |
| IV 崩塌 | 月度发生 | 30%-50% | 进场必须在 IV 低位 |
| 黑天鹅 | 季度发生 | 50%-100%(卖方) | 禁用裸卖,只用 Iron Condor |
| 流动性陷阱 | 偶发 | 5%-10% | 只做 ATM |
